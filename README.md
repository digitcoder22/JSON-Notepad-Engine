## JSON Notepad Engine (Python)
This is a notepad engine that is written in Python but also uses JSON.
It should help beginners on how python and json work together and how JSON formatting works.

## Features
- Multiline text editor
- Easy to edit template
- Uses JSON
- Lightweight

## How to run the template
1. Clone the repo by opening Command Prompt or any other terminal and typing `https://github.com/digitcoder22/JSON-Notepad-Engine.git`
2. Open any IDE with Python support (I use VS Codium)
3. Run the script.

## Where is the .py?
The .py is in the root folder of json_engine.

## What file to edit?
Edit the main.py file.
